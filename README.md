# Gather EMS UI
Responsive frontend-only recreation of the supplied EMS Design PDF.

## Run
Open `index.html` in a browser. No installation or build step is needed.

## Screens
Landing page, organizer dashboard, event details and mock registration, schedule/venue/vendor operations, participant ticket preview.

## Demo interactions
Page navigation, ticket price updates, mock registration confirmation, and setup checklist completion percentage.

## Limitations
Static sample data only. No backend, database, real authentication, payment processing, live QR code, or persistent registration. The source design contains some USD sample values; this version uses BDT amounts for the Bangladesh context.
